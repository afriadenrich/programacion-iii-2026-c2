## REST
REGLAS DE COMO VAMOS A TRABAJAR NUESTRA COMUNICACIÓN (es un estándar)

- El mensaje tiene una estructura definida y estandarizada. HTTP. 
- REST / "Descansar" -> inactiva hasta que tenga que hacer algo.
- Cada petición comienza y termina sin necesidad de guardar ni persisitr nada el el servidor.  
- Cada petición es ATÓMICA y recibe TODOS los datos necesarios para funcionar sin recordar nada.
- "Sin estado" -> El servidor no va a guardar información de las peticiones que pasaron.

- Cada petición debe resolverse con lo que recibe de información, no debe depender de otras peticiones, debe usar HTTP y debe estandarizar sus respuesas (JSON)
